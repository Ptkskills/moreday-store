# MOREDAY Store

Loja virtual estática para a marca MOREDAY, com identidade esportiva premium e layout responsivo.

## Arquivos
- `index.html` — estrutura da página.
- `styles.css` — identidade visual e adaptações para telas menores.
- `script.js` — filtros, busca, menu móvel e sacola demonstrativa.

## Como visualizar
Abra `index.html` no navegador ou publique o repositório com GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

## Antes de vender
1. Confirme os preços e atualize os atributos `data-price` e os valores exibidos nos cartões em `index.html`.
2. Adicione links reais de compra/checkout aos produtos.
3. Configure pagamento, frete, política de troca, privacidade e contato.
4. Conecte o formulário de newsletter a um serviço real de e-mail.
5. Substitua as imagens externas pelas fotos finais dos produtos e verifique os direitos de uso.

**Nota:** o carrinho atual é apenas uma demonstração no navegador; ele não processa pagamentos nem cria pedidos. O site ainda não está conectado a estoque, frete ou gateway de pagamento.
